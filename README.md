# Personality Prediction Analysis

Supervised machine learning project in R that predicts personality type
(Introvert/Extrovert) from behavioral data.
Completed as part of the Master's in Business and Data Analytics,
KNUST, Ghana (BDA 554), July 2025.

## What I did
- Merged and cleaned two Kaggle datasets into a 1,834-observation dataset
- Built and compared three models: Logistic Regression, Decision Tree
  and K-Nearest Neighbors, using the tidymodels framework in R
- Achieved up to 95% classification accuracy and AUC above 0.75
- Found that time spent alone and social event attendance were the
  strongest predictors

## Files
- Personality_Prediction_Analysis.R: full analysis code
- Personality_Prediction_Analysis_Presentation.pptx: findings and
  business applications (HR, marketing, psychology)
